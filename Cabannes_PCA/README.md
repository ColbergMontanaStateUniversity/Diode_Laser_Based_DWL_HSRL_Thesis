This code generates the training set for generating the Cabannes spectra as used in the DWL retrieval and in the HSRL calibration. Requires MATLAB and the MATLAB parallel computing toolbox.

User-adjustable settings are in the `%% user inputs` section at the top of the script. The colormaps and saving output directories will also need to be replicated or changed.

The Tenti S6 code in the `Tenti_s6_code` folder was downloaded from the MATLAB File Exchange (https://www.mathworks.com/matlabcentral/fileexchange/29108-coherent-spontaneous-rayleigh-brillouin-scattering-spectra) and is included under its original license.
